# Moj prvi program

Računalniški program lahko izpiše kratko sporočilo. Naslednji primer je napisan v jeziku **JavaScript**.

## Kaj program izpiše?

Besedilo, ki ga program izpiše, je: *Pozdravljeni, tečajniki!*

## Primer programa

```javascript
console.log("Pozdravljeni, tečajniki!");
```

Ukaz `console.log` prikaže besedilo na zaslonu. Besedilo med narekovaji lahko spremenimo. Na primer, program lahko izpiše *Danes se učimo Markdown*.

## Preizkus programa

1. Odpri spletno okolje za JavaScript.
2. Vnesi zgornji ukaz in ga zaženi.
3. Spremeni besedilo med narekovaji ter program znova zaženi.

Za dodatno pomoč obišči [MDN Web Docs – console.log](https://developer.mozilla.org/en-US/docs/Web/API/console/log_static).

**Namig:** Narekovaji naj ostanejo okoli besedila.
